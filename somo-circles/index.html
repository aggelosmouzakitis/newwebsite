Somo Circles · Somatic shaking και ομαδική επεξεργασία

Somo Circles

Somatic shaking σε μικρή ομάδα, με χώρο για να παρατηρήσετε, να συζητήσετε και να επεξεργαστείτε όσα προκύπτουν.

Δεν χρειάζεται προηγούμενη εμπειρία με σωματικές πρακτικές ή ομάδες.

Δείτε τα επόμενα Somo Circles→Τι γίνεται σε μια συνάντηση →

Τι είναι

Δύο μέρη στην ίδια συνάντηση

Το Somo Circles συνδυάζει μια καθοδηγούμενη πρακτική somatic shaking με συζήτηση σε μικρή ομάδα.

Κατά τη σωματική πρακτική, μπορεί να εμφανιστεί τρέμουλο στα πόδια ή σε άλλα σημεία του σώματος. Πριν ή μετά την πρακτική υπάρχει χρόνος για να παρατηρήσετε τι συνέβη και, εφόσον το θέλετε, να το συνδέσετε με σκέψεις, συναισθήματα ή καταστάσεις από τη ζωή σας.

Το προσωπικό μοίρασμα είναι προαιρετικό.

Somatic shaking

Τι συμβαίνει στην πράξη

Το somatic shaking ξεκινά με απλές στάσεις και κινήσεις που ενεργοποιούν ή κουράζουν ήπια συγκεκριμένες μυϊκές ομάδες. Μετά από αυτή την ενεργοποίηση, μπορεί να εμφανιστεί τρέμουλο στο σώμα.

Παραμένετε σε πλήρη επίγνωση και αποφασίζετε πόσο θέλετε να προχωρήσετε.

Πώς εξελίσσεται

  • Ξεκινάτε με απλές στάσεις ή κινήσεις.
  • Το τρέμουλο μπορεί να εμφανιστεί σταδιακά.
  • Μπορείτε να αλλάξετε την ένταση ή τη θέση σας.
  • Μπορείτε να ξεκουραστείτε ή να σταματήσετε.
  • Δεν χρειάζεται να προκαλέσετε κάποια συγκεκριμένη αντίδραση.

Τι μπορείτε να συζητήσετε

  • Όσα παρατηρήσατε στο σώμα.
  • Συναισθήματα ή σκέψεις που εμφανίστηκαν.
  • Επαναλαμβανόμενα μοτίβα έντασης.
  • Πώς ήταν να βρίσκεστε μέσα στην ομάδα.

Η ομαδική επεξεργασία

Δεν είναι μόνο μια σωματική πρακτική

Η συζήτηση μπορεί να γίνει πριν ή μετά το somatic shaking, ανάλογα με τη μορφή της συνάντησης.

Ο συντονιστής βοηθά τη συζήτηση να παραμένει σαφής και σχετική με την εμπειρία. Κανείς δεν πιέζεται να μοιραστεί κάτι προσωπικό.

Μια συνάντηση

Τι γίνεται σε ένα Somo Circle

01
Άφιξη και εισαγωγή
Εξηγούμε τη δομή, τις βασικές οδηγίες και τους τρόπους με τους οποίους μπορείτε να προσαρμόσετε ή να σταματήσετε την πρακτική.
02
Σωματική προετοιμασία
Απλές κινήσεις και στάσεις προετοιμάζουν το σώμα χωρίς έντονη άσκηση.
03
Somatic shaking
Αφήνετε το τρέμουλο να αναπτυχθεί στον βαθμό που σας είναι άνετος.
04
Συζήτηση και επεξεργασία
Υπάρχει χρόνος για να παρατηρήσετε και, αν θέλετε, να μοιραστείτε όσα προέκυψαν.
05
Ολοκλήρωση
Η πρακτική τελειώνει σταδιακά, με χρόνο για ξεκούραση και επιστροφή στον συνηθισμένο σας ρυθμό.

Η σειρά μπορεί να αλλάξει ανάλογα με τη μορφή της συνάντησης.

Σε ποιους μπορεί να ταιριάξει

Ίσως σας ενδιαφέρει αν

  • Παρατηρείτε συχνά ένταση στο σώμα σας.
  • Περνάτε πολύ χρόνο αναλύοντας όσα σας συμβαίνουν.
  • Δυσκολεύεστε να αναγνωρίσετε τις σωματικές σας αισθήσεις.
  • Θέλετε να εξερευνήσετε την εμπειρία σας με κάτι περισσότερο από συζήτηση.
  • Σας ενδιαφέρει να παρατηρήσετε πώς αντιδράτε μέσα σε μια μικρή ομάδα.

Τι δεν είναι

Σαφείς προσδοκίες πριν συμμετάσχετε

  • Δεν είναι μάθημα γυμναστικής.
  • Δεν είναι παράσταση ή επίδειξη.
  • Δεν υπόσχεται συναισθηματική εκτόνωση.
  • Δεν αποτελεί ιατρική υπηρεσία.
  • Δεν αντικαθιστά εξατομικευμένη υποστήριξη από επαγγελματία υγείας.

Έλεγχος και όρια

Εσείς αποφασίζετε πόσο θα συμμετέχετε

Μπορείτε να μειώσετε την ένταση, να αλλάξετε στάση, να κάνετε παύση ή να σταματήσετε εντελώς.

Δεν χρειάζεται να μιλήσετε ή να εξηγήσετε όσα παρατηρήσατε. Ο συντονιστής δίνει σαφείς οδηγίες για το πώς μπορείτε να επανέλθετε ή να ξεκουραστείτε.

Πώς να το εξηγήσετε σε κάποιον

Το Somo Circles είναι μια μικρή ομαδική εμπειρία που συνδυάζει somatic shaking με συζήτηση και επεξεργασία. Οι συμμετέχοντες κάνουν απλές σωματικές ασκήσεις, παρατηρούν όσα προκύπτουν και μπορούν, εφόσον το θέλουν, να τα εξερευνήσουν μαζί με την ομάδα.

Για συμβούλους, coaches και άλλους επαγγελματίες

Αν θέλετε να το προτείνετε σε κάποιον

Το Somo Circles μπορεί να ενδιαφέρει ανθρώπους που θέλουν να συνδέσουν τη λεκτική κατανόηση με όσα παρατηρούν στο σώμα τους.

Πρόκειται για ομαδική βιωματική εμπειρία. Δεν αντικαθιστά την εξατομικευμένη υποστήριξη που μπορεί ήδη να λαμβάνει κάποιος.

Συχνές ερωτήσεις

Χρειάζεται προηγούμενη εμπειρία;

Όχι. Οι ασκήσεις είναι απλές και εξηγούνται από την αρχή.

Πρέπει να μιλήσω;

Όχι. Μπορείτε να συμμετέχετε στη σωματική πρακτική χωρίς να μοιραστείτε κάτι προσωπικό.

Μπορώ να σταματήσω το shaking;

Ναι. Μπορείτε να μειώσετε την ένταση, να αλλάξετε στάση, να ξεκουραστείτε ή να σταματήσετε.

Είναι το ίδιο με τη yoga;

Όχι. Το Somo Circles χρησιμοποιεί διαφορετική σωματική προετοιμασία και περιλαμβάνει ομαδική επεξεργασία.

Είναι ψυχοθεραπεία;

Όχι. Είναι μια συντονισμένη βιωματική ομαδική εμπειρία. Δεν αποτελεί ψυχοθεραπεία, ιατρική υπηρεσία ή αντιμετώπιση κάποιας πάθησης.

Μπορώ να συμμετέχω αν ήδη συνεργάζομαι με κάποιον ειδικό;

Ναι. Αν έχετε οποιαδήποτε αμφιβολία για το αν η εμπειρία είναι κατάλληλη για εσάς, συζητήστε το με τον επαγγελματία που σας υποστηρίζει.

Τι πρέπει να φορέσω;

Άνετα ρούχα με τα οποία μπορείτε να κινηθείτε.
